# IPL Korea Field Navigator

Innovation Exchange Korea 2026의 핵심 인사이트를 FY27 Korea 전략, 고객 병목 기반 세일즈 메시지, Discovery 질문, Next Best Play로 전환한 정적 웹사이트입니다.

## 주요 기능

- 핵심 발표 → FY27 Korea 우선순위 Strategy Bridge
- 7개 고객 병목 기반 Sales Play Explorer
- 병목·고객 역할·산업별 대화 메시지 생성기
- Create → Govern → Validate → Operate → Learn 라이프사이클 시각화
- Discovery → Assessment → Workshop → PoC → Business Case 실행 흐름
- 반응형 디자인, 키보드 탐색, reduced-motion 지원

## 로컬 실행

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 여세요.

## 배포

프레임워크나 빌드 과정이 없는 순수 HTML/CSS/JavaScript 사이트입니다. GitHub Pages에서 repository root를 배포 소스로 지정하면 됩니다.

## 근거 및 사용 범위

2026년 11월 내부 행사 아젠다, 현장 세일즈 플레이북, FY27 Korea Sales Enablement 전략 자료를 바탕으로 작성했습니다. 공개 배포 위험을 낮추기 위해 고객명, 금액, 파이프라인 수치 등 기밀 가능성이 있는 세부 정보는 포함하지 않았습니다. 세일즈 메시지와 Next Play는 현장 해석 및 권고이며, 계정 상황과 승인된 제품 로드맵을 기준으로 검증 후 사용해야 합니다.
